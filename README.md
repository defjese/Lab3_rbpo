# Спортивный турнир

REST API для организации спортивных турниров. Команды подают заявки, организатор их одобряет, запускает турнир, назначает матчи, вносит счёт и завершает турнир с итоговой таблицей.

## Сущности

| Сущность | Что хранит |
|---|---|
| Пользователь (`/api/users`) | логин, пароль (хеш), имя, роль |
| Команда (`/api/teams`) | название, капитан (пользователь), состав команды |
| Турнир (`/api/tournaments`) | название, лимит команд, статус |
| Заявка (`/api/team-applications`) | команда, турнир, статус заявки |
| Матч (`/api/matches`) | турнир, две команды, счёт, статус |

**Связи:** у команды один капитан и много участников (пользователей). Заявка связывает команду и турнир. Матч принадлежит турниру и связывает две команды.

**Статусы:**

- турнир: `PLANNED` → `IN_PROGRESS` → `FINISHED`
- заявка: `PENDING` → `APPROVED` или `REJECTED`
- матч: `SCHEDULED` → `FINISHED`

**Правила, которые гарантирует база данных:** названия команд и турниров уникальны, в турнире минимум 2 команды, команда не играет сама с собой, счёт не бывает отрицательным, команда подаёт на турнир только одну заявку.

Для каждой сущности есть CRUD: `GET` список, `GET` по id, `POST`, `PATCH`, `DELETE`.

## Бизнес-операции

Если условия не выполнены, API отвечает `409`.

| Операция | Запрос | Когда можно |
|---|---|---|
| Одобрить заявку | `POST /api/team-applications/{id}/approve` | турнир ещё не начался, заявка новая, лимит команд не исчерпан |
| Запустить турнир | `POST /api/tournaments/{id}/start` | турнир ещё не начался, одобрено минимум 2 команды; остальные заявки отклоняются автоматически |
| Назначить матч | `POST /api/matches/schedule` | турнир идёт, обе команды одобрены, такой пары в турнире ещё нет |
| Завершить матч | `POST /api/matches/{id}/finish` | матч ещё не завершён, турнир идёт |
| Завершить турнир | `POST /api/tournaments/{id}/finish` | турнир идёт, есть матчи, все матчи завершены; в ответе турнирная таблица (победа 3 очка, ничья 1) |

## Запуск

1. Создать в PostgreSQL базу `tournament_db` и пользователя `tournament_app` с правами только на чтение и запись данных (SELECT, INSERT, UPDATE, DELETE).
2. Скопировать `.env.example` в `.env` и вписать пароль:

   ```
   DB_HOST=localhost
   DB_PORT=5432
   DB_NAME=tournament_db
   DB_USERNAME=tournament_app
   DB_PASSWORD=
   ```

3. Запустить приложение. Таблицы создаются автоматически, тестовые данные (пользователи, команды, турниры, заявки) добавляются сами.

Приложение работает на `http://localhost:8080`.

## Проверка

Импорт `postman/tournament.postman_collection.json` в Postman и запустить коллекцию целиком (Run collection). Она создаёт данные, проверяет CRUD и все бизнес-операции, а в конце удаляет созданное.
